# Bank Account Management — Setup

To run the project you'll need Python and the required packages listed in `requirements.txt`.

PowerShell (recommended):

```
# (optional) Create and activate a virtual environment
python -m venv .venv; .\.venv\Scripts\Activate.ps1

# Install dependencies
python -m pip install -r requirements.txt

# Run the application
python "Bank account management.py"
```

If the `python` command is not available, try `py -3` instead.
